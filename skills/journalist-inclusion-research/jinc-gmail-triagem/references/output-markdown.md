# jinc-gmail-triagem: template de markdown diário

Arquivo: `/opt/data/journali/triagem-YYYY-MM-DD.md`

## Cabeçalho
- `# Triagem Gmail - últimos 15 dias`
- `Run: <YYYY-MM-DD HH:MM TZ>`
- `Janela: <YYYY-MM-DD> .. <YYYY-MM-DD>`
- `Total candidatas (após filtro): <N>`
- `Releases: <R>`
- `Sugestões de pautas: <S>`

## Releases

Para cada item:

### Tipo: release
- **Fonte:** <from>
- **Assunto:** <subject>
- **Data do e-mail:** <date>
- **Link/Identificador:** <messageId + URL se existir>
- **Resumo:**
  - <linha 1>
  - <linha 2>
  - <linha 3>
- **Ângulo inclusivo sugerido:**
  - <bullet>
  - <bullet>
  - (opcional)
- **Palavras-chave encontradas:**
  - <lista>

## Sugestões de pautas

Mesmo formato dos items de Releases.
